# code-refactor-agent

An automated code quality and refactoring Agent built on the Claude API. Scans your codebase for technical debt, generates refactoring PRs, and self-validates via unit tests in a closed-loop pipeline.

| Metric | Result |
|---|---|
| Code review efficiency | ↑ 80% |
| Daily token usage | ~5M (peak 8M) |
| PR first-pass rate | 73% |
| Tech debt resolved | 1,200+ items |

---

## How it works

```
scan → refactor (LLM) → PR submit → test + retry (×3) → Slack alert if unresolved
```

### Stage 1 — Scan (`agent/scanner.py`)
AST analysis + custom rule engine against your repo. Outputs a structured JSON debt manifest with file path, issue type, severity score, and code context. Detects: naming violations, high cyclomatic complexity, DRY violations, missing type annotations, dead imports.

### Stage 2 — Refactor (`agent/refactor_llm.py`)
Feeds the debt manifest + `rules/arch_spec.yaml` to Claude. Multi-turn context preserves cross-file consistency. Each fixable item produces: refactored code, change rationale, impact scope, and rollback notes. Complex architectural issues are flagged for human review.

### Stage 3 — PR submit (`agent/pr_publisher.py`)
Calls the GitHub API to branch, commit, and open a PR. PR description is auto-generated by Claude — includes change summary, debt category, affected modules, and rollback plan.

### Stage 4 — Test + retry (`agent/test_runner.py`)
Triggers CI and watches for failures. On failure, Claude reads the error log, generates a fix patch, and re-runs — up to 3 iterations. If unresolved, `agent/notifier.py` fires a Slack webhook with the root-cause analysis.

## Quick start

```bash
git clone https://github.com/your-org/code-refactor-agent
cd code-refactor-agent
pip install -r requirements.txt
cp .env.example .env   # fill in ANTHROPIC_API_KEY and GITHUB_TOKEN
python main.py --repo your-org/your-repo --dry-run
```

Remove `--dry-run` to submit real PRs.

## Configuration

| Variable | Description | Default |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API key | required |
| `GITHUB_TOKEN` | GitHub PAT with repo + PR write | required |
| `MAX_TOKENS_PER_DAY` | Daily token budget | 5000000 |
| `RETRY_LIMIT` | CI retry attempts | 3 |
| `SLACK_WEBHOOK_URL` | Slack incoming webhook for alerts | optional |
| `ARCH_SPEC_PATH` | Path to architecture spec YAML | `rules/arch_spec.yaml` |
| `DEBT_RULES_PATH` | Path to debt rule thresholds YAML | `rules/debt_rules.yaml` |

## Project structure

```
code-refactor-agent/
├── main.py                  # CLI entrypoint
├── config.py                # Env-based config loader
├── agent/
│   ├── scanner.py           # AST tech debt detection
│   ├── refactor_llm.py      # Claude patch generation
│   ├── pr_publisher.py      # GitHub PR creation
│   ├── test_runner.py       # CI polling + retry loop
│   └── notifier.py          # Slack human-escalation alert
├── rules/
│   ├── arch_spec.yaml       # Architecture conventions
│   └── debt_rules.yaml      # Detector thresholds
├── tests/
│   └── test_scanner.py
└── .github/workflows/ci.yml
```
